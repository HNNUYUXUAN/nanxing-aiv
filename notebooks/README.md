## 执行与更新

在项目根目录使用锁定的 Python 环境。下列入口先验证聚合结果、重绘结果图并运行两例，再从干净内核执行十本 Notebook：

```powershell
.venv\Scripts\python.exe -X utf8 -B scripts/reproduce.py --notebooks
```

执行记录和已显示的原生图表保存在 `build/notebooks/`；`execution.json` 记录每本状态、用时和输出图数。Notebook 不读取密钥或发起模型调用。图表由单元中的计算代码生成，`save_figure` 同时输出 PDF、SVG、PNG 与来源哈希。

修改叙述或单元模板后，使用以下生成入口：

```powershell
# 重建00/08/09，维护01–07，再挂载各章的最终分析单元
.venv\Scripts\python.exe -X utf8 -B scripts/build_research_notebooks.py

# 仅更新最终分析叙述和挂载单元；重复执行保持相同内容
.venv\Scripts\python.exe -X utf8 -B scripts/finalize_notebook_narrative.py
```

最终分析单元由 `scripts/finalize_notebook_narrative.py` 维护，使用稳定单元标识；原有合成实验保留。生成器按首个代码单元识别运行准备，概念 Markdown 不承担代码初始化。`scripts/build_notebooks.py` 为旧初始化器，不用于日常更新。

人审比较单位为相同题目、相同评审角色，共16对。记录总耗时24.55→19.41人分钟，A减少、B增加；完全一致4/8→6/8，后者含2题共同弃权。固定顺序、同题重复、共同AI推荐及计时停顿限制因果解释。

严格B检查的已观测逐回合时间戳为0，前瞻合格记录与学生簇均为0，故未拟合。CSV创建时间不能填入回合时间，100条/30簇门槛也不表示功效保证。

