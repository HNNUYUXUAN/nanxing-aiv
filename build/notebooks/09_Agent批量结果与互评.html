Agent 批量结果与独立复核¶

当前状态¶

两个快速模型独立标注全部符合条件的学生回合；两个强模型在固定分层随机子集和高风险回合独立复核。 原始输入部分读取显式选定、哈希固定的 frozen 快照；后半部读取 results/final-analysis/ 的聚合表。所有单元离线计算，不发起模型调用。

范围与方法¶

单位为 08 本定义的学生 Q 回合；12 条工程合成控制与真实回合分列。若冻结时仍有未完成任务， 所有比例明确保留计划分母和已完成分母，未完成不会计入弃权。

关键假设¶

一致性只在同题、双模型均产生结构化输出的配对子集计算；另列双方都有数字标签的分母。 强模型的复核子集受到风险路由与分层抽样影响，不能把两组一致率差写成互评收益或准确率变化。

独立判断与复核¶

两基础模型与两复核模型分别独立判断任务、贡献两维。随机复核、风险复核和配对复跑保留各自分母；结论可继续弃权或保留争议。模型一致性与重复性各有对应统计量。
