# 最终答辩图页播放器

直接双击 [index.html](index.html) 离线打开。播放器按 `slides/final/images/01.png` 至 `17.png` 顺序引用原生 PNG，不转码、不缩写文件。01–10 为主讲，11–16 为技术备答，17 为问答结束致谢。正式放映前确认 17 张图片均在 `images/`；缺失文件在屏幕上仅呈现空白背景。

左侧缩略图可直接跳页。左右方向键、Page Up/Down、空格翻页；Home/End 到首尾。**正式放映先按浏览器 F11** 进入浏览器全屏，再按 F 或点“全屏投影”，使原图独占屏幕；Esc 退出图页全屏，F11 退出浏览器全屏。
