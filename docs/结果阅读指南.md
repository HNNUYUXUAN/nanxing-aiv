# 从研究发现到教学行动

真实数据结果、条件推演与合成试验分别说明不同的问题。所有核心数值和分母以 [summary.json](../results/final-analysis/summary.json) 为统一入口。

| 问题与发现 | 可核对的证据 | 教学动作 | 适用条件 |
| --- | --- | --- | --- |
| 任务要求与已展示贡献是两个测量对象，候选覆盖不同 | [六级分布及同回合配对图](../results/final-analysis/fig01_dimensions.png)、`descriptive.csv`、`joint-levels.csv` | 要求学生为分析、评价等任务补充自身推理与核验过程 | 用同回合双候选比较二者；边际候选均值只描述各自子集 |
| 强复核会暴露新的争议，且随机与高风险子集表现不同 | [固定随机流程图](../results/final-analysis/fig02_random_flow.png)、`flow-comparison.csv`、`flow-transitions.csv` | 优先查看争议及判断变化记录，并展示原文依据 | 同样本比较覆盖、弃权、分歧和改变；评价准确性需要独立参考 |
| 候选子集的学期差异受选择性缺失影响 | [未知标签范围图](../results/final-analysis/fig03_unknown_labels.png)、`unknown-label-bounds.csv`、`term-contrast-bounds.csv` | 暂缓将候选平均分用于跨学期教学效果比较 | 范围保持已有候选固定，将其他回合的潜在层级取遍 L1–L6 |
| 两名评审的辅助复评用时方向不同，完全一致中包含共同弃权 | [人审观察图](../results/final-analysis/fig04_human_pairs.png)、`human-role-timing.csv`、结果清单的 `human` | 把建议用于定位待核查证据，保留人工决定与变更记录 | 相同题目、固定顺序、共同推荐；计时包括停顿 |
| 小样本、缺失指标和标签改动扩大条件范围 | [敏感性图](../results/final-analysis/fig05_score_sensitivity.png)、`score-range-sensitivity.csv` | 优先补充缺失证据；范围重叠时暂缓给出先后顺序 | 三套固定权重；改标预算向上取整；比较限同学期、有任务候选的单位 |
| 工具堆叠和贴合理想分布能改变指标 | 结果清单 `redteam`；Notebook 06 | 工具广度单列解释；同时展示取消其权重的代价；DHI用于分布诊断 | 文本扰动受实际模型与样本量限制；DHI攻击为解析分析 |
| 缺少会话与工具信息时，部分指标停止计算 | [可运行案例](../scripts/demo_evidence_chain.py)；Notebook 07 | 明确请求补充会话关系与工具来源，展示仍可计算的部分 | 案例标签为保存的合成输入；不据案例推断真实学生效果 |

## 主要计算入口

- `scripts/build_final_analysis.py`：在授权环境中校验冻结输入，复算流程合并、真实分布、人审记录、时间资格及条件范围。
- `scripts/reproduce.py`：从仓库内的公开汇总表重绘结果图、检查统计口径，实际运行两例合成演示。
- `scripts/execute_notebooks.py`：为十本 Notebook 分别启动干净内核，执行后保存图文页面与来源清单。
- `scripts/demo_evidence_chain.py`：单独运行正常和缺失证据案例。

图表标题中的“候选”保留模型判断的性质；“条件范围”表明对未知量与误差预算的假设。完整 AIV、独立学习效果和因果效应由各自所需证据决定。
