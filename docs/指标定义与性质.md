# 指标定义、证明与边界 v1

对已核验为同一会话内原始相邻回合的有效边集合 E，学生提问标签为 L∈{1,…,6}。删去弃权或抽样遗漏后，剩余记录的位置相邻不构成新的源相邻边。无证据不补标签。跨课程、工具机会和量表测量不变性未经校验前，不把同一数值范围等同于公平可比。

1. **ABL_raw** 为原始均值 mean(L)，范围 [1,6]；**ABL** 为进入评分的归一值 (mean(L)−1)/5，范围 [0,1]。旧384基线的 `semester-descriptions.json` 历史键 `ABL` 保存的是原始均值，读取时按 `ABL_raw` 解释。**HOT** 为 L≥4 的比例，百分数展示时乘 100。空样本均不可判断。
2. **CTQ** = 1/2 + Σ_(i,j∈E)(L_j−L_i)/(10|E|)。每个差值在 [−5,5]，故 CTQ∈[0,1]。上升边相对 1/2 基准的贡献非负，下降非正；恒定序列为 1/2。无有效边为不可判断，不能记零。
3. **对称 DHI** = 1−Σ|p_k−q_k|/2，即 1−总变差距离。其范围 [0,1]，仅 p=q 时取 1，对此距离单调递减。
4. **非对称 DHI**：设 d=Σ_(k=1,…,5)[2(F_p(k)−F_q(k))₊+(F_q(k)−F_p(k))₊]，DHI_a=1−d/M，M 为六个单点分布的 d 最大值。d 为凸函数，单纯形内任一点是顶点凸组合，故 d≤M，范围 [0,1]；累计分布全部一致等价 p=q。低层累计过量受两倍惩罚，此系数是教育设计假设。
5. **MAB** 原值为去重工具数 m，评分映射 min{1,log(1+m)/log5}，单调、饱和且边际递减；候选回合所需工具身份有任一缺失时，完整广度不可判断。观察到的工具数可以另列，但不能代替完整 MAB；全部缺失不能当 m=0。
6. **AIV** =100Σw_kx_k，w≥0、Σw=1。故各子指标单调非减且有界 [0,100]，各项贡献可分解。正权重指标缺失时整体弃权；不自动重归一剩余权重。

默认理想分布 q=(.10,.15,.20,.25,.20,.10) 是围绕分析层较高、兼顾基础与创造的**教学设计假设**，并非观察得到的最优分布。不同教学阶段应先固定目标，再评价，禁止根据待评分学生拟合有利目标。

## CTQ 的长度与分段条件

本式按有效边数平均，不是总分随轮数累加。固定边集合分成任意若干块，按每块边数加权平均后与原值完全相同。因此保存跨块边的等长等幅跃迁一致。

若切分操作删除跨块边，或复制轮次引入额外零跃迁，边集合改变，得分不保证不变。令保留边比例为 1−r，由全体均值分解可得删除边前后 CTQ 差不超过 r（每边归一分数在 [0,1]）。逐轮复制、整段复制的实测偏离保留在红队表。路径差值还会望远镜消去：它主要刻画净方向，不能完整表示探索深度。因此本式属于透明基线，尚不能声称对任意对话长度和任意切分全面鲁棒。

## 权重与误差传播

预先固定三套权重：均衡 (.2,.2,.2,.2,.2)，高阶 (.1,.5,.2,.15,.05)，过程 (.1,.2,.4,.25,.05)，顺序为 ABL/HOT/CTQ/DHI/MAB。比较时归一规则与目标 q 固定。权重逐项 ±10% 后重归一；排名区间为扰动分位范围，不称统计置信区间。

若标签错误通过混淆矩阵 T 表示，则观测层级分布 p_obs=Tᵀp_true。ABL/HOT 的偏差是该分布偏差的线性投影。标签翻转数量 s、样本量 n 固定时，归一 ABL 误差≤s/n，HOT误差≤s/n，总变差 DHI 误差≤s/n。CTQ 还依赖错标点涉及的边，对固定 E，每条受影响边归一误差≤1，可用受影响边比例给界。MAB 若只受标签误差不变。AIV 绝对误差≤100Σw_k|δx_k|。

模型概率直接抽样仅是条件模拟，存在共同错误时独立抽样可能低估不确定性。正式实验须比较共享错误冲击和人工校准混淆矩阵，采用学生级重抽样传播到排名。

## 红队发现与保守使用

固定标签示例 [2,3,4,5] 上，工具数从 1 增到 4 使均衡 AIV 增加约 11.3865，虽然认知标签完全不变。饱和只能限制增分，不能证明实质价值。保守对照将 MAB 作为描述性指标，综合权重设 (.25,.25,.25,.25,0)，工具堆叠改变量归零；代价是总分不再奖励工具广度。该对照仍保留并单独报告题面 MAB，且需核实真实有益工具使用是否被低估。

对分段攻击，不能识别跃迁时输出不可判断。冗长、认知动词注入、复制 AI 答案属于文本级攻击，需要额外模型与人审实验；固定标签红队不能替代它们。
