# 阅读、验证与迁移

仓库提供论文、演示图页、代码、Notebook、合成示例和汇总结果。建议先读 [README](../README.md)，再选择下面的计算范围。

## 公共输入：汇总验证与合成演示

Python 依赖固定于 `requirements-lock.txt`。在新的设备上创建本地环境并安装依赖；本项目 Windows 工作区使用 `.venv/Scripts/python.exe`。

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements-lock.txt
.venv\Scripts\python.exe -X utf8 -B scripts/reproduce.py
```

此命令核对公开汇总表的分母、缺失范围和敏感性单调性，重绘五张结果图，运行正常及缺失证据两例合成计算。输出在 `build/reproduction/`，执行记录为 `receipt.json`。它没有重新标注原始学生文本，也没有从原始学生记录重算真实统计。

```powershell
# 从干净内核执行十本 Notebook，并保留图文结果
.venv\Scripts\python.exe -X utf8 -B scripts/reproduce.py --notebooks

# 现场短计算：两种案例都实际求值
.venv\Scripts\python.exe -X utf8 -B scripts/demo_evidence_chain.py
```

Notebook 的合成实验使用固定种子；公开汇总单元读取 `results/final-analysis/`。未接入私有资料时，对应原始数据单元显示输入状态。真实来源的汇总结果与合成试验分别标记。

## 授权输入：从冻结记录重新计算

原始数据仅供具有相应授权的研究环境读取。授权环境保留 `notebooks/research-inputs.json` 中固定的快照与派生材料、t3 计划、逐回合索引以及已封存评审记录。

```powershell
.venv\Scripts\python.exe -X utf8 -B scripts/reproduce.py --authorized-inputs --notebooks
```

这一模式先运行 `scripts/build_final_analysis.py`。脚本校验冻结清单、标签与输入连接，逐条复算正式合并规则，再计算聚合结果。它不调用模型服务，也不改写封存记录。缺少所需输入或哈希不一致时会停止；请按数据授权补全输入，不以公开汇总代替逐条来源。

## 替换输入与模型

核心计算位于 `aiv/metrics.py` 和 `aiv/models.py`。任务标签使用 L1–L6；工具标识、会话边界及可信相邻关系分别支撑 MAB 和 CTQ。未知字段保持 `None`。新增来源应保留来源摘要、观测单位、时间含义和字段缺失率，并重新检验比较条件。

多模型判断协议见 `aiv/fast_strong_workflow.py`。更换模型或提示后应建立新的结果版本，重新检查结构化响应、原文证据匹配、弃权、同题分歧及重复性。缓存和标签记录属于相应模型条件，不能自动继承为新模型的准确性证据。

## 论文与图页

论文源文件为 `paper/main.tex`，多文件 XeLaTeX 构建入口为 `scripts/build_latex.ps1`。Windows 已配置环境可执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build_latex.ps1 -Source paper/main.tex -OutputDirectory build/paper
```

源稿使用 CUMCMThesis 固定版本的类文件和样式。第三方模板的来源和获取方式见 [第三方资源来源](第三方资源来源.md)；公共树仅分发许可明确的原创源文件。中文字体需与源稿配置相符。已编译 PDF 可直接阅读。

最终图页的顺序、讲稿和放映入口见 [演示说明](../slides/README.md)。科研统计图由计算程序生成，演示整页图由已核验的图片生成流程制作。
