# 复现：从两例计算到论文图表

先运行两例合成计算，再按需要执行 Notebook 或重绘论文图。三条路径都使用仓库内的输入，不调用模型服务。

| 想完成什么 | 入口 | 需要什么 | 得到什么 |
| --- | --- | --- | --- |
| 看懂证据如何改变报告 | `scripts/demo_evidence_chain.py` | Python 与项目依赖 | 两例指标、分数或条件范围、补证建议 |
| 逐步计算并调整参数 | `scripts/execute_notebooks.py --workers 1` | 项目依赖、绘图字体 | 十本已执行 Notebook、离线 HTML、图表来源清单 |
| 核对公开统计并重绘五组论文图 | `scripts/reproduce.py` | 项目依赖、绘图字体、XeLaTeX | 十个子图、五组图与复现收据 |

只阅读成果，可直接打开[论文 PDF](../build/paper/main.pdf)、[Notebook 导读](../notebooks/README.md)或[20 页路演](../slides/README.md)。

## 1. 运行两例合成计算

在仓库根目录创建环境并安装固定依赖。以下为 Windows PowerShell 命令；macOS / Linux 使用 `.venv/bin/python` 替换解释器路径。

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements-lock.txt
.venv\Scripts\python.exe -X utf8 -B scripts/demo_evidence_chain.py
```

两例都使用保存的合成任务标签 `[2, 3, 4, 5]`。完整证据例的均衡 AIV 为 **61.65**（界面保留一位小数为 **61.7**）；去掉会话关系与工具来源后，CTQ、MAB 和综合点分为 `null`，条件范围为 **36–76**。

| 完整证据 | 缺少会话与工具证据 |
| --- | --- |
| ![完整证据时，工作台显示合成 AIV 61.7](../slides/roadshow/images/09.png) | ![相同标签缺少证据时，显示条件范围36–76与补证建议](../slides/roadshow/images/10.png) |

上图是同一合成计算的工作台展示。终端输出还包含各项指标和报告动作，便于逐项核对。需要保留结果时运行：

```powershell
.venv\Scripts\python.exe -X utf8 -B scripts/demo_evidence_chain.py --output build/demo-examples.json
```

## 2. 执行 Notebook

从[Notebook 导读](../notebooks/README.md)选择一个问题交互运行，或一次执行全部十本：

```powershell
.venv\Scripts\python.exe -X utf8 -B scripts/execute_notebooks.py --workers 1
```

执行器为每本 Notebook 启动干净内核，将图文输出保存回 `.ipynb`，并生成 `build/notebooks/index.html`。打开该页面可离线阅读、展开代码和下载图表；`execution.json` 记录执行状态，`figure-manifest.json` 记录图表来源。

公开统计读取 [results/final-analysis](../results/final-analysis/summary.json)，合成实验使用固定种子或保存的标签。原始记录相关单元根据输入可用性显示状态。真实观察、合成试验和条件范围在图文中分别注明。

绘图使用 **SimSun（宋体）**及 **Times New Roman**。执行前可检查字体：

```powershell
.venv\Scripts\python.exe -c "from matplotlib.font_manager import findfont; print(findfont('SimSun', fallback_to_default=False)); print(findfont('Times New Roman', fallback_to_default=False))"
```

字体由操作系统提供；缺少时需安装有使用权限的字体。已导出的图表可直接阅读。

## 3. 重绘论文统计图

该路径先检查分母、未知标签范围和敏感性单调性，再绘制十个子图，最后用论文的 LaTeX 模板组合为五组图，同时执行两例合成计算。

```powershell
.venv\Scripts\python.exe -X utf8 -B scripts/reproduce.py
```

重绘额外需要可用的 **XeLaTeX**，以及 `standalone`、`ctex`、`graphicx`、`caption`、`subcaption`、`fontspec`、`xeCJK`。Python 依赖安装不会安装 TeX 或字体。组图由 [figure_groups](../paper/figure_groups/) 和 [figure_style.tex](../paper/figure_style.tex) 统一排版，输出 PNG 为 600 dpi，并保留 PDF / SVG。

产物写入 `build/reproduction/`。检查 `receipt.json` 中的 `checks`、`source_summary_sha256`、`examples_executed` 和 `plots_generated`，可核对本次执行范围。公开复现验证已发布汇总与公式；逐条原始统计需要下一节的授权输入。

## 4. 从授权记录重新计算

在已具备数据授权及完整冻结输入的研究环境中执行：

```powershell
.venv\Scripts\python.exe -X utf8 -B scripts/reproduce.py --authorized-inputs --notebooks
```

此模式先运行 `build_final_analysis.py`，校验 `notebooks/research-inputs.json` 固定的快照、派生材料、计划及封存评审记录，再逐条复算正式合并规则与统计。缺少输入或哈希不符会停止；原始学生记录不随公共仓库分发。

## 迁移自己的数据

核心公式见 [metrics.py](../aiv/metrics.py) 与 [models.py](../aiv/models.py)。任务层级取 L1–L6；会话相邻关系与工具标识分别支持 CTQ 和 MAB。缺失字段保留 `None`，并记录来源、观测单位、时间含义和缺失率。

更换模型或提示时，以[判断与复核协议](../aiv/fast_strong_workflow.py)为入口建立新的结果版本，再检查结构化响应、原文证据匹配、弃权、分歧和重复性。论文编译见[论文说明](../paper/README.md)，代码和材料许可见 [LICENSES.md](../LICENSES.md)。
